# Stratégie de retour à l'emploi — Regards SI et démonstrateurs

Date de formalisation : 26 septembre 2026

## 1. Architecture générale

La stratégie de retour à l'emploi repose sur trois niveaux complémentaires :

### 1. CV classique — PDF

Le PDF reste le CV de premier niveau.

Il doit être :
- sobre ;
- lisible rapidement ;
- immédiatement compréhensible par un recruteur ;
- centré sur l'expérience, les responsabilités, les résultats et les compétences ;
- autonome : il doit fonctionner même si le lecteur ne consulte rien d'autre.

### 2. CV augmenté — Regards SI

**Regards SI est le cœur du dispositif.**

Il ne remplace pas le CV classique : il l'augmente.

Regards SI donne accès à :
- la doctrine ;
- la manière de penser ;
- la méthode ;
- les convictions ;
- le recul sur l'expérience ;
- les démonstrateurs ;
- les preuves concrètes.

Regards SI doit assurer la cohérence d'ensemble et empêcher toute impression de dispersion.

### 3. Démonstrateurs et démultiplicateurs

Les autres projets sont des preuves et des terrains d'application.

Ils ne doivent pas être présentés comme une collection de projets parallèles.

Ils démontrent la même philosophie dans des contextes différents.

Périmètre :
- **OPAAIA / GUSTAVE** ;
- **4 sites CFO Artistes** ;
- **CFO Agence Média** ;
- **CFO Print / Publishing** autour des 4 artistes ;
- **Antoine Delmas**.

Leur rôle est de démultiplier la preuve apportée par Regards SI.

---

## 2. Risque principal : la dispersion

La diversité des projets peut être perçue comme une dispersion si elle n'est pas explicitement reliée par une doctrine commune.

Le **pas de côté** est valorisable.

La dispersion ne l'est pas.

La règle est donc :

> **Regards SI donne la cohérence. Les démonstrateurs changent de terrain, pas de philosophie.**

Le message à éviter :
> J'ai beaucoup de projets.

Le message à construire :
> J'applique une même doctrine professionnelle à plusieurs contextes pour en éprouver la robustesse.

---

## 3. Philosophie commune des démonstrateurs

Tous les démonstrateurs reposent sur la même colonne vertébrale :

> **La Data au cœur.  
> L'IA comme intelligence aidante.  
> L'opérationnel métier comme finalité.  
> L'humain comme arbitre.**

### Data au cœur

La donnée doit être qualifiée, structurée, historisée, exploitable et reliée à une décision ou à un usage concret.

### IA aidante

L'IA n'est ni un substitut au métier ni une autorité autonome.

Elle aide à :
- comprendre ;
- détecter ;
- synthétiser ;
- rédiger ;
- automatiser ;
- accélérer.

### Opérationnel métier comme finalité

La technologie n'est jamais la finalité.

Elle doit améliorer :
- un processus ;
- une décision ;
- une expérience utilisateur ;
- une production ;
- un pilotage ;
- une activité métier.

### Humain arbitre

Le contrôle humain reste indispensable pour :
- valider ;
- contextualiser ;
- arbitrer ;
- assumer la décision finale.

## 4. Rôle de chaque démonstrateur

### Regards SI

Rôle : **CV augmenté, doctrine et cohérence générale.**

Regards SI explique :
- comment je pense ;
- comment j'aborde un problème ;
- comment je relie métier, SI, Finance, Data et IA ;
- comment je construis ;
- pourquoi les autres démonstrateurs existent.

### OPAAIA / GUSTAVE

Rôle : **démonstrateur principal SI / ERP / opérations métier / IA.**

Il doit démontrer :
- compréhension des processus ;
- modélisation métier ;
- architecture applicative ;
- intégration ;
- pilotage ;
- adaptabilité ;
- IA au service des utilisateurs ;
- capacité à concevoir un produit industrialisable et en marque blanche.

### CFO Artistes

Rôle : **démonstration d'industrialisation d'un même socle sur plusieurs instances.**

Les quatre sites doivent montrer :
- réutilisation d'architecture ;
- contextualisation par artiste ;
- Data ;
- contenu ;
- automatisation ;
- cohérence UX ;
- capacité multi-instance.

### CFO Agence Média

Rôle : **lecture B2B de l'écosystème CFO.**

Il doit montrer :
- architecture ;
- données ;
- IA ;
- automatisations ;
- gouvernance ;
- processus ;
- modèle économique ;
- exploitation réelle d'une structure.

### CFO Print / Publishing

Rôle : **démonstrateur publishing et produit éditorial.**

Il doit montrer la capacité à :
- concevoir un produit ;
- décliner une ligne éditoriale ;
- industrialiser une production ;
- articuler contenu, visuel, Data et diffusion.

### Antoine Delmas

Rôle : **un autre regard.**

La fiction permet d'observer :
- les organisations ;
- les décisions ;
- les transformations ;
- les dilemmes ;
- les conséquences humaines.

Ce n'est pas un projet périphérique : c'est une autre représentation des mêmes problématiques professionnelles.

## 5. Finalité professionnelle

L'objectif ultime de cet écosystème est sa **valorisation professionnelle**.

Le principe est :

> **Le CV affirme. Regards SI explique. Les démonstrateurs prouvent.**

L'objectif n'est pas de présenter une accumulation de réalisations personnelles, mais de démontrer une capacité actuelle à :

- concevoir ;
- structurer ;
- arbitrer ;
- modéliser ;
- relier ;
- industrialiser ;
- exploiter ;
- faire évoluer.

La monétisation éventuelle de certains actifs ou produits est un bonus bienvenu, mais elle n'est pas la finalité première du dispositif.

## 6. Positionnement rémunération

La stratégie vise des fonctions de niveau :
- Directeur SI Finance ;
- Directeur Applications / Enterprise Applications ;
- DSI adjoint ;
- Directeur Transformation SI ;
- DSI de BU / filiale ;
- rôles équivalents à forte responsabilité métier et SI.

Repères de positionnement :
- **125 k€ fixe : seuil d'entrée visé** ;
- **135–145 k€ fixe : cœur de cible** ;
- **150 k€ et plus : cible haute selon périmètre et exposition**.

Le dispositif de démonstrateurs doit contribuer à rendre crédible ce positionnement en apportant des preuves de capacité actuelle.

## 7. Lecture des 26 années chez SII

Une première expérience professionnelle de 26 ans est rare.

Elle ne doit pas être racontée comme une période de confort ou d'immobilisme.

Elle doit être lue comme :

> **26 ans d'engagement, de confiance renouvelée et d'élargissement continu des responsabilités.**

Cette durée démontre :
- fidélité dans l'engagement ;
- capacité à traverser plusieurs cycles technologiques ;
- capacité à accompagner la transformation d'une entreprise ;
- profondeur de connaissance des mécanismes d'organisation ;
- responsabilité assumée dans la durée.

La société elle-même s'est transformée au fil de cette période.

Cette transformation a constitué une richesse majeure du parcours.

Elle est aussi à l'origine de la divergence finale : les attentes, priorités et manières d'exercer le rôle ont progressivement évolué jusqu'à créer un écart avec la manière souhaitée d'exercer la fonction.

La fin de collaboration doit être présentée comme **la fin logique et choisie d'un cycle long**, sans dénigrer ce qui a précédé.

## 8. La période 2026

### Intitulé retenu pour le CV

**2026 — Consolidation professionnelle**

Formulation de référence :

> **Consacrer du temps à formaliser plus de vingt-cinq ans d'expérience, à appréhender concrètement les nouvelles technologies et à les mettre à l'épreuve dans des démonstrateurs opérationnels.**

Cette formulation est volontairement :
- sobre ;
- active ;
- non défensive ;
- non assimilable à une reconversion ;
- non assimilable à une formation ;
- non assimilable à un échec entrepreneurial.

### Sens de la consolidation

La consolidation est concrète.

Elle produit :
- Regards SI ;
- GUSTAVE / OPAAIA ;
- CFO et ses déclinaisons ;
- CFO Agence Média ;
- CFO Publishing ;
- Antoine Delmas ;
- des architectures ;
- des pipelines ;
- de la documentation ;
- des systèmes réellement opérés.

La logique est :

> **ne pas dire que les compétences sont à jour : le montrer.**

## 9. Maladie, hospitalisation et reprise

Le CV PDF ne doit pas être médicalisé.

La santé n'est pas le sujet du premier niveau de recrutement.

En revanche, Regards SI peut aller plus loin lorsque cela a du sens.

Le récit doit rester factuel :
- épisode de santé important ;
- plusieurs mois d'hospitalisation ;
- rééducation ;
- réapprentissage de la marche ;
- séquelles visibles ;
- reprise progressive ;
- utilisation de cette période pour préparer le retour à l'emploi, écrire, formaliser et construire.

Il faut éviter deux écueils :
- le récit subi ;
- le récit héroïque surjoué.

La ligne est :

> **une contrainte réelle transformée en période de construction et de consolidation.**

Les apprentissages mobilisables professionnellement peuvent inclure :
- priorité à l'essentiel ;
- progression par étapes ;
- acceptation du réel ;
- importance de la qualité de l'information ;
- recours aux bons experts ;
- interdépendance ;
- rôle central de l'humain dans les systèmes complexes.

---

## 10. Récit global de retour à l'emploi

La ligne directrice est désormais :

> **26 ans d'engagement et de transformation chez SII → divergence progressive en fin de cycle → choix de clore cette étape → période de consolidation concrète → retour sur le marché avec une expérience renforcée par de nouveaux outils, de nouvelles pratiques et des démonstrateurs opérationnels.**

La fin de collaboration avec SII était choisie.

La période suivante a comporté des contraintes subies, notamment le chômage et un épisode de santé important.

Le récit professionnel ne nie pas ces contraintes, mais met l'accent sur l'usage qui a été fait de cette période :
- réflexion ;
- écriture ;
- formalisation ;
- construction ;
- mise à l'épreuve des technologies récentes ;
- préparation du retour à l'emploi.

Le retour sur le marché doit donc être présenté non comme un simple retour à l'état précédent, mais comme un retour avec **de nouveaux arguments**.

---

## 11. Règles de ton

Toujours privilégier :
- volontaire plutôt que subi ;
- factuel plutôt que héroïque ;
- concret plutôt que théorique ;
- senior plutôt que scolaire ;
- cohérent plutôt que foisonnant ;
- preuve plutôt que déclaration.

Éviter :
- reconversion ;
- transition, lorsqu'elle suggère un changement de métier ;
- formation, si elle réduit la démarche à un apprentissage académique ;
- initiative entrepreneuriale, si elle peut être interprétée comme une tentative ayant échoué ;
- résilience utilisée comme slogan ;
- tout récit victimaire ou spectaculaire.

> **La Data au cœur. L'IA comme intelligence aidante. L'opérationnel métier comme finalité. L'humain comme arbitre.**

### Retour sur le marché

> **La même profondeur d'expérience, enrichie de nouveaux outils, de nouvelles pratiques et de preuves concrètes.**

---

## 13. Conséquence pour la qualité des démonstrateurs

Les démonstrateurs doivent être traités comme des **produits de référence**.

Ils doivent être :
- fonctionnellement solides ;
- visuellement aboutis ;
- architecturalement cohérents ;
- documentés ;
- explicables en entretien ;
- reliés explicitement à une compétence professionnelle.

Leur niveau de finition doit être cohérent avec le positionnement salarial et le niveau de responsabilité visés.

Ils ne sont pas des hobbies présentés dans un portfolio.

Ils constituent des **preuves de capacité professionnelle actuelle**.
